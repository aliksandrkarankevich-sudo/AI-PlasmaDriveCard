# Roadmap

## Текущие линии

- `0.96.0` — стабильная линия из `dev/v0.96-beta5`; подготовка публикации, без заявления о состоявшемся релизе.
- `dev/v0.97-beta1` — следующая разработка (`0.97.0-beta1`), без тега и Release.
- Все более ранние версии — исторические; прежние ветки сохраняются без изменений. Удаление веток и защита `main` не входят в переход.
- План и проверки перед публикацией: [RELEASE_TRANSITION.md](docs/RELEASE_TRANSITION.md).

## Следующая разработка

- Проверить масштабирование 100–200%, autoFit с разными размерами значков и сохранность профилей.
- Проверить сложные LUKS/LVM-устройства, нагрузку опроса и восстановление после зависания команд.
- Непроверенные пункты ниже остаются открытыми: присвоение стабильного статуса не означает их автоматического выполнения.

## После 1.0

- [ ] **Мигрировать `EdgeFadeBackground` на QSB-шейдер** — GPU-рендеринг и качество; сначала измерить выигрыш на реальном рабочем столе.

Порядок исторической задачи: написать `EdgeFade.frag` (GLSL `#version 440`, `layout(std140)` uniforms), собрать командой `qsb --glsl "100 es,120,150" --hlsl 50 --msl 12 -o EdgeFade.frag.qsb EdgeFade.frag` (требует `qt6-shadertools` на машине разработчика), заменить Canvas-блок на `ShaderEffect { fragmentShader: Qt.resolvedUrl("EdgeFade.frag.qsb") }`, закоммитить оба файла (`.frag` + `.qsb`).
