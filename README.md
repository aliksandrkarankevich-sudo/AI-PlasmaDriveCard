# Drive Cards

![Plasma 6](https://img.shields.io/badge/KDE%20Plasma-6-blue)
![Version](https://img.shields.io/badge/version-0.95.0--beta2-orange)
![License](https://img.shields.io/badge/license-GPL--3.0--or--later-green)

Небольшой полупрозрачный виджет дисков для KDE Plasma 6 и CachyOS. Показывает смонтированные локальные разделы, свободное место, файловую систему и краткое имя физического накопителя.

English: a compact configurable drive-card widget for KDE Plasma 6.

## Реализованные функции

- Автоматически находит смонтированные локальные разделы через `findmnt` и сопоставляет их с физическими накопителями через `lsblk`.
- Показывает название раздела, свободное и общее место, процент заполнения, файловую систему и краткое имя физического диска.
- Открывает раздел в файловом менеджере нажатием по всей строке; отдельной кнопки открытия нет.
- Подсвечивает интерактивную строку при наведении и нажатии, показывает курсор-ссылку и поддерживает клавиатурную активацию.
- Предлагает три основных значка: диск, папка и открытая папка.
- Показывает активность чтения/записи и меняет цвет заполнения при предупредительном или критическом уровне.
- Автоматически подбирает высоту под число разделов либо использует заданную максимальную высоту и прокрутку.
- Поддерживает русский и английский интерфейс, масштаб текста, толщину индикатора, отступы и интервалы обновления.
- Использует цвет Plasma или пользовательский цвет для фона и текста.
- Создаёт симметричный переход фона в прозрачность слева, справа, сверху и снизу, включая мягкие углы.

## Переход прозрачности

Фон рисуется один раз, поэтому его центральная непрозрачность соответствует настройке без двойного наложения. Горизонтальная и вертикальная маски перемножаются: ширина и форма перехода одинаковы на четырёх сторонах, а значение `0 px` полностью отключает затухание.

Настройки:

- **Непрозрачность фона** — непрозрачность центральной области.
- **Прозрачность края** — насколько прозрачными становятся внешние края.
- **Ширина перехода** — глубина затухания от каждого края.
- **Кривая перехода** — скорость изменения прозрачности внутри перехода.
- **Скругление и радиус** — форма внешних углов.

## Открытие разделов

Вся строка раздела является одной кнопкой: значок, название, сведения, индикатор и свободная область открывают точку монтирования. При наведении строка подсвечивается; отдельная кнопка папки удалена как дублирующая.

Выбор «Диск / Папка / Открытая папка» меняет только основной значок строки и не создаёт дополнительную кнопку.

## Установка

```bash
git clone https://github.com/aliksandrkarankevich-sudo/AI-PlasmaDriveCard.git
cd AI-PlasmaDriveCard
git switch fix/v0.95.0-beta2-edge-fade
./scripts/check.sh
./scripts/install.sh
```

После установки добавьте **Drive Cards** через режим редактирования рабочего стола Plasma. Для обновления уже установленной версии снова выполните `./scripts/install.sh`.

## Сборка

```bash
./scripts/check.sh
```

Установочный пакет появится в `dist/cachyos-drive-card-0.95.0-beta2.plasmoid`, а контрольная сумма — в `dist/SHA256SUMS`.

## Сообщить о проблеме

Перед созданием сообщения проверьте существующие [Issues](https://github.com/aliksandrkarankevich-sudo/AI-PlasmaDriveCard/issues). Новую ошибку добавляйте через форму [Bug report](https://github.com/aliksandrkarankevich-sudo/AI-PlasmaDriveCard/issues/new?template=bug.yml).

Укажите:

- версию Drive Cards;
- CachyOS/дистрибутив, версию Plasma и сеанс Wayland/X11;
- ожидаемое и фактическое поведение;
- точные шаги воспроизведения;
- снимок экрана или короткое видео для визуальных проблем;
- вывод `journalctl --user -b | grep -Ei 'plasmashell|drivecard|qml'` для ошибок загрузки.

Перед публикацией удалите имена пользователей, домашние пути, UUID дисков и другие персональные данные. Запросы новых функций добавляйте через [Feature request](https://github.com/aliksandrkarankevich-sudo/AI-PlasmaDriveCard/issues/new?template=feature.yml).
