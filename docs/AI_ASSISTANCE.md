# AI assistance

## Scope

AI-PlasmaDriveCard does not include artificial-intelligence features. It does not send disk information to an AI service, make AI-based decisions, or require an online account to work.

Artificial intelligence is used as a development assistant. It may help draft code, documentation, tests, design proposals, and troubleshooting steps.

## Human responsibility

The repository maintainer reviews proposed changes, decides what is included, tests releases on KDE Plasma, and remains responsible for published code and release notes.

## Transparency

Significant AI-assisted design or implementation decisions should be documented in commit messages, issues, pull requests, or project documentation when useful for review and maintenance.
