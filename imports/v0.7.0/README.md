# Карточка дисков 0.7.0

Изменения:
- плавный край через штатный Qt Quick `MultiEffect`, без набора видимых прямоугольных ступеней;
- автоматическая высота через минимальный, предпочтительный и максимальный размер представления;
- файловая система и краткий идентификатор физического диска;
- отдельные переключатели отображения этих сведений;
- полный путь и источник остаются во всплывающей подсказке.

Обновление в Fish:
```fish
kpackagetool6 --type Plasma/Applet --upgrade ~/Загрузки/cachyos-drive-card-0.7.0.plasmoid
systemctl --user restart plasma-plasmashell.service
```

Если геометрия старого экземпляра не пересчиталась, удалите только экземпляр виджета с рабочего стола и добавьте его заново.
