# Карточка дисков 0.6.0

Новое: автоматическая высота по числу дисков; ограничение 82% рабочей высоты экрана и прокрутка; высота строки; отдельная непрозрачность фона и текста; включаемое скругление и радиус; регулируемые прозрачность края и ширина плавного перехода.

Обновление в Fish:

```fish
kpackagetool6 --type Plasma/Applet --upgrade ~/Загрузки/cachyos-drive-card-0.6.0.plasmoid
systemctl --user restart plasma-plasmashell.service
```

Если старый экземпляр удерживает сохранённый ручной размер, удалите его с рабочего стола и добавьте заново после обновления.

Зависимости: Plasma 6, plasma5support, util-linux. Лицензия: GPL-3.0-or-later.
