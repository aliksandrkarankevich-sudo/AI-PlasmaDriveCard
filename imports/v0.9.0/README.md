# Drive Cards 0.9.0

Плазмоид Plasma 6 для отображения смонтированных локальных файловых систем.

## Зависимости

- Plasma 6
- plasma5support
- util-linux (`findmnt`, `lsblk`)
- POSIX shell (`/bin/sh`)

## Архитектура

- Один короткий запрос `findmnt` через настраиваемый интервал проверяет только изменение списка монтирований.
- Полный `findmnt --json` + `lsblk --json` выполняется после изменения списка и по таймеру обновления места.
- Фон рисуется одним Canvas: скруглённый прямоугольник и две взаимно умножаемые альфа-маски X/Y. Поэтому переход действует со всех четырёх сторон и в углах.
- Фактическая высота корневого объекта не присваивается. Плазмоиду передаётся только `Layout.preferredHeight`; при нехватке места работает прокрутка.

## Установка

```fish
kpackagetool6 --type Plasma/Applet --upgrade ~/Загрузки/cachyos-drive-card-0.9.0.plasmoid
systemctl --user restart plasma-plasmashell.service
```
