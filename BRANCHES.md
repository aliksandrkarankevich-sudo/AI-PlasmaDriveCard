# Правила веток / Branch Rules

## Структура

| Ветка | Роль | Редактировать? |
|---|---|---|
| `main` | Текущая релизная версия. Неизменна до выхода следующей версии. | ❌ НЕТ |
| `dev/v*` | Ветка в разработке. Здесь ведётся вся работа. | ✅ ДА |
| `fix/*` | Хотфикс к релизу. После проверки мержится в `dev/*`. | ✅ ДА |
| `feat/*` | Отдельная фича. Мержится в `dev/*` когда готова. | ✅ ДА |

## Цикл выпуска

```
dev/v0.96-beta2  ────  работа, коммиты, тесты  ────►
                                                        │
                              Старый main ─► тег v0.95.0 (архив)
                                                        │
                                            merge ─► main  (новая релизная)
```

1. Вся работа ведётся в `dev/v*`.
2. Когда версия готова:
   - Текущий `main` получает тег (`v0.95.0`) — уходит в архив
   - `dev/v*` мержится в `main` — становится новой релизной версией
   - `dev/*` ветка закрывается
3. `main` **никогда не редактируется напрямую** — только через мерж из `dev/*`.
