# Changelog

## [0.96.0-beta4] — не выпущено

Ветка `dev/v0.96-beta4`. Тег и GitHub Release не созданы.

### Изменения

- Удалён неиспользуемый C++-плагин (`CMakeLists.txt`, `src/`): виджет остаётся чисто QML-пакетом, сборка не требует компиляции.
- В окне настроек добавлены краткие подсказки к параметрам (размер, значки, оформление, обновление, пороги, профили). Имена ключей конфигурации `cfg_*` не менялись, существующие настройки сохраняются.
- Версия в `package/metadata.json` — `0.96.0-beta4`.
- Аудит: удалены неиспользуемые `_lastScanMs` и свойства делегата; изменения геометрии больше не запускают сканирование дисков.
- Hotplug сравнивает содержимое снимка `/proc`, а не число строк. Индикаторы активности записываются в модель только при изменении и сбрасываются при переключении настройки.
- Добавлена защита от некорректной структуры JSON профилей и записей переопределений; уточнены подсказки масштаба текста и кривой затухания.
- `check.sh` больше не устанавливает пакет: используется новый `build.sh --no-install`. Проверка ZIP выполняется через Python с контролем CRC, без ложного успеха при отсутствующем `unzip`.
- Добавлены 16 регрессионных тестов JavaScript-логики (`node --test scripts/test-logic.cjs`); это не замена тестированию QML в Plasma.
- Подробности и открытые вопросы: [аудит beta4](docs/AUDIT_BETA4.md).

## [0.96.0-beta3] — 2026-10-05

### Изменения

- Выпуск ветки `dev/v0.96-beta3` объединён в `main` (PR #10).
- Добавлен `scripts/install-from-github.sh`: установка последнего выпуска с проверкой SHA256 (PR #5). Если стабильных релизов нет, скрипт автоматически берёт последний pre-release; подсказка по перезапуску Plasma теперь через `systemctl --user`.
- Настроены GitHub Actions: проверка пакета, загрузка сборочного артефакта и автоматическая публикация релизов.
- Восстановлен исполняемый бит у `scripts/*.sh`.
- README: актуализированы версия, установка, перезапуск Plasma, добавлен раздел «Авторы».
- В `metadata.json` указаны авторы: разработчик и соавтор Perplexity AI.

### Авторы

- **Разработчик:** aliksandrkarankevich-sudo.
- **Соавтор:** Perplexity AI.

## [0.95.0-beta2] — 2026-09-21

### Исправлено

- **Четырёхсторонний переход в прозрачность.** Раньше градиент работал только горизонтально. Теперь `EdgeFadeBackground.qml` применяет переход ко всем четырём сторонам виджета.
- **Открытие диска нажатием по строке.** Вся строка диска теперь является кликабельной (значок, название, сведения, индикатор). Подсветка при наведении.
- **Удалена отдельная кнопка открытия** (`folder-open` ToolButton в конце строки).
- **Удалён параметр `openOnRowClick`** из конфигурации — открытие нажатием теперь является постоянным поведением.
- **Исправлена альфа-композиция центра:** фон рисуется один раз, без двойного наложения прямоугольников, центр соответствует заданной непрозрачности.
- Возвращён `Plasmoid.preferredRepresentation: Plasmoid.fullRepresentation`.
- Исправлен URL раздела — `openTarget` теперь всегда добавляет `/` к пути для корректного открытия в файловом менеджере.
- `scripts/build.sh` исключает файлы `*.backup*` из архива `.plasmoid`.
- Добавлены `scripts/install.sh`, `scripts/install-from-github.sh`, `scripts/uninstall.sh`.
- `release.yml` автоматически определяет `prerelease` по наличию alpha/beta/rc в версии.
