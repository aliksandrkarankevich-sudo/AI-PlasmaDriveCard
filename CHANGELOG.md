# Changelog

## [0.95.0-beta2] — 2026-09-20

### Fixed

- Переход прозрачности теперь применяется ко всем четырём сторонам виджета (новый компонент `EdgeFadeBackground.qml`).
- Симметричная кривая перехода для левого/правого и верхнего/нижнего краёв.
- Непрозрачность центральной части не накапливается от двойного наложения прямоугольников.
- Открытие раздела работает нажатием по всей строке диска.
- URL раздела нормализуется с завершающим `/` для корректного открытия в Dolphin.
- Курсор меняется на указатель над интерактивной строкой.

### Removed

- Отдельная кнопка открытия папки в конце каждой строки.
- Параметр `openOnRowClick` из конфигурации (открытие по строке теперь постоянная функция).

### Added

- `scripts/install.sh` — установка из клона Git.
- `scripts/install-from-github.sh` — загрузка и установка последней версии из GitHub Releases с проверкой SHA-256.
- `scripts/uninstall.sh` — удаление виджета.
- `scripts/build.sh` теперь исключает резервные и временные файлы из `.plasmoid`.
- Восстановлена строка `Plasmoid.preferredRepresentation`.

## [0.95.0-beta1] — 2026-09-19

### Added

- Стили значков диска и папки.
- Масштаб текста и толщина полосы заполнения.
- Пользовательские цвета фона и текста.
- Индикация операций чтения/записи.
- Автоматическая сборка GitHub Actions.

### Changed

- Переработан расчёт автоматической высоты.
- Восстановлено полное представление Plasma.
