# Участие в проекте

## Ошибки

Перед созданием Issue проверьте существующие сообщения. Используйте форму Bug report и заполните версию CachyOS/дистрибутива, Plasma, Wayland/X11, версию виджета и точные шаги воспроизведения. Общие замечания и идеи по тестовым версиям можно оставить через форму Feedback.

## Изменения кода

1. Создайте fork и ветку `fix/...` или `feature/...`.
2. Не меняйте идентификатор `io.github.cachyos.drivecard`.
3. Выполните `./scripts/check.sh`.
4. Соберите пакет через `./scripts/build.sh`.
5. Проверьте виджет в Plasma 6.
6. Создайте Pull Request и опишите визуальные изменения.

QML следует сохранять читаемым; пользовательские строки должны иметь русский и английский варианты.

## Работа с ИИ

Проект разрабатывается с участием ИИ (соавтор: Perplexity AI). Если вы используете ИИ-инструменты, укажите это в описании Pull Request и проверьте результат вручную на реальной системе.
